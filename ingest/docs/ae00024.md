# `ae00024.py` — 구조화 API 캐시 (accnutAdtorNmNdAdtOpinion)

## 개요

OPENDART 정기보고 *구조화 API* 중 회계감사인·감사의견 정보를 제공하는 `accnutAdtorNmNdAdtOpinion.json` (코드 AE00024) 응답을 `(corp_code × bsns_year × reprt_code)` 단위로 캐시합니다.

휴리스틱 파싱 결과(`parse_results`)와 교차검증할 때 유용합니다. 예: 구조화 API 가 알려준 회계법인명 = `parse_results.auditor_firm` 인가?

## 구성 요소

| 심볼 | 역할 |
|---|---|
| `fetch_ae00024(client, corp_code, bsns_year, reprt_code="11011")` | 단건 호출, raw JSON 반환 |
| `cache_ae00024_for_filings(client, conn, *, limit, progress)` | 배치: `filings` 의 (corp, 연도) 조합을 모두 캐시 |
| `_DEFAULT_REPRT_CODE = "11011"` | 사업보고서 코드 (1분기=11013, 반기=11012, 3분기=11014) |

## 동작 흐름

```
select_distinct_corp_years(conn) ─► [(corp_code, "2023"), (corp_code, "2024"), ...]
        │
        ▼
for (corp, year) in pairs:
    │
    ├─ fetch_ae00024(client, corp, year, "11011")
    │       └─ HTTPS GET .../accnutAdtorNmNdAdtOpinion.json?...
    │
    ├─ 성공: upsert_ae00024(status=resp.status, payload=resp)
    └─ 실패: upsert_ae00024(status='error', payload=None, message=str(e))
    │
    └─ conn.commit()
```

## 응답 페이로드 예 (단순화)

```json
{
  "status": "000",
  "message": "정상",
  "list": [
    {
      "corp_code": "00126308",
      "bsns_year": "2024",
      "adtor": "삼일회계법인",
      "adt_opinion": "적정",
      "adt_reprt_dt": "20250320"
    }
  ]
}
```

`payload_json` 컬럼에는 위 JSON 전체가 그대로 저장됩니다. 단 `status != '000'` 이면 `payload_json = NULL`.

## 예제

### CLI

```powershell
# filings 의 모든 (법인, 연도) 조합 캐시
python -m dart_kam ae00024

# 최근 100개 조합만
python -m dart_kam ae00024 --limit 100 --verbose-http
```

### 라이브러리 — 단건 호출

```python
from dart_kam.config import load_settings
from dart_kam.dart_client import DartClient
from dart_kam.ae00024 import fetch_ae00024

settings = load_settings()
settings.require_key()
with DartClient(settings) as client:
    data = fetch_ae00024(client, "00126308", "2024", "11011")
    print(data["status"])
    for row in data.get("list", []):
        print(row.get("adtor"), row.get("adt_opinion"))
```

### 라이브러리 — 캐시 결과 조회

```python
import json, sqlite3

cur = conn.execute("""
    SELECT corp_code, bsns_year, payload_json
    FROM ae00024_cache
    WHERE status = '000'
    ORDER BY bsns_year DESC
    LIMIT 5
""")
for corp, year, payload in cur:
    obj = json.loads(payload)
    for row in obj.get("list", []):
        print(f"{corp} {year}: {row.get('adtor')} / {row.get('adt_opinion')}")
```

## FAQ

**Q. `bsns_year` 의 정의가 무엇인가요?**
A. `filings.rcept_dt` 의 *첫 4글자* (접수일 기준 연도)입니다. 사업연도 자체와 다를 수 있지만 (12월 결산이 아닌 경우), 대부분 케이스에서 1대1 매칭됩니다.

**Q. `reprt_code` 가 사업보고서(11011) 로 고정인가요?**
A. 네. KAM 분석은 사업보고서 단위가 가장 일반적이라 기본값을 11011로 고정했습니다. 1Q/반기/3Q 도 필요하면 `fetch_ae00024(..., reprt_code="11013")` 등으로 직접 호출 가능 — 다만 캐시 unique 키가 `(corp, year, reprt)` 라 충돌 없이 저장됩니다.

**Q. 응답이 "데이터가 없습니다" 인데 캐시는 채워지나요?**
A. 네, `status` 코드가 다른 값(`013` 등)으로 채워지고 `payload_json` 은 NULL 입니다. 빈 결과도 캐시에 기록되어 재호출을 막습니다.

**Q. 실패 후 재시도하려면?**
A. 같은 명령을 다시 실행하면 됩니다. 캐시는 UPSERT 이므로 새 응답이 기존 행을 덮어씁니다. 단 *현재는 무조건 모든 조합을 다시 호출* 합니다 — "에러만 재시도" 가 필요하면 `select_distinct_corp_years` 를 확장하면 됩니다.

**Q. `limit` 정렬 기준은?**
A. 사업연도(`bsns_year`) **내림차순**. 가장 최근 연도부터 처리됩니다.

**Q. 호출량이 많은데 시간이 걸려요.**
A. 법인 수 × 연도 수 만큼 호출되므로 일반적으로 수만 건입니다. `request_sleep_sec=0.12` 기본값 기준 분당 약 500건. 대시보드 갱신용으로는 야간 1회 실행으로 충분합니다.
